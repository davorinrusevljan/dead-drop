# Issue Tracker

GitHub Issues on `davorinrusevljan/dead-drop` (same repo).

## Workflow

- List: `gh issue list --state open`
- View: `gh issue view <number>`
- Create: `gh issue create --title "..." --body "..."`
- Branch naming: `<type>/<slug>` (e.g. `docs/rework`, `fix/drop-name-validation`)

Commit messages may reference issues (`#123`, `Closes #45`); treat those as the spec source for the Spec axis during code review.
